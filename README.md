# «Тихий клас» (Quiet Class v6) — Bouncy Balls Pro

> **Інтерактивний візуальний шумомір, менеджер навчальних груп та ігровий асистент контролю тиші для шкіл, уроків, смарт-дошок (TV) і проекторів.**
> Повністю автономний PWA-додаток із процедурною графікою Canvas, багатошаровим інтерфейсом **Liquid Glass**, компресованим Web Audio синтезатором та живою Verlet-фізикою.

---

## Ключові можливості (v6.0)

### 1. Аудіосистема, миттєве прев'ю та повторення сигналів (`src/audio/`)
Працює однаково точно на **віддалених вебкамерах (2–4 м)**, вбудованих мікрофонах ноутбуків та гарнітурах, а звукові сигнали чітко прорізають гамір класу на динаміках телевізора чи проектора:

* **Web Audio DSP-тракт мікрофона (`src/audio/mic.js`)**:
  * **120 Hz Highpass Filter**: зрізає низькочастотний гул кулерів ПК/проектора, шум кондиціонера та вібрації парт.
  * **2.2 kHz Speech Presence Filter**: підсилює діапазон розбірливості мовлення (`+3.5 dB`), виділяючи шепіт і приголосні над фоновим шумом.
  * **Preamp Gain Boost**: програмне підсилення вхідного сигналу від `0.5×` до `4.5×` (за замовчуванням `2.2×` для вебкамер).
  * **Анти-луп захист (`isMutingMic`)**: автоматично ігнорує власні звукові ефекти гри протягом `750 мс`, щоб динаміки ТВ не викликали повторне спрацювання мікрофона.
* **Синтезатор сигналів із компресором (`src/audio/sfx.js`)**:
  * **Апаратний `DynamicsCompressorNode` (`-16 dB`, ratio `6:1`) + Makeup Gain (`1.75×`)**: забезпечує щільне, гучне та чисте звучання без кліпінгу навіть на слабких динаміках (регулювання гучності до `120%`).
  * **Миттєве прев'ю**: клік по будь-якому типу сигналу в панелі вчителя (або зміна повзунка гучності чи натискання кнопки «Тест») одразу програє обраний звук.
  * **4 звукові сигнали при перевищенні шуму**:
    1. **«Тссс!» (`shush`)**: дзвінкий початковий транзієнт уваги (`1760 Гц`) + двоформантний шиплячий потік (`2300–4800 Гц`).
    2. **«Радар» (`beep`)**: подвійний двотональний гармонічний імпульс (`triangle` + `sine`, `880 Гц -> 1046.5 Гц`).
    3. **«Дзвоник» (`bell`)**: подвійний металевий удар настільного дзвоника вчителя (*Дзінь-дзінь!* на гармоніках `1318.5 / 2637 / 3820 Гц`).
    4. **«Аркада» (`arcade`)**: ретро 8-бітний каскадний сигнал уваги з фільтрацією низьких частот.
  * **Інтервал повторення сигналу при тривалому шумі (`alertRepeatSec`)**:
    * Налаштовується прямо в панелі: **«Кожні 2 с»**, **«Кожні 4 с»** (за замовчуванням), **«Кожні 8 с»** або **«1 раз»**.
    * Доки рівень шуму залишається в червоній зоні, сигнал, банер попередження, тряска екрана та підкидання кульок повторюються за обраним інтервалом.

### 2. Реактивна Verlet-фізика кульок (`src/world/physics.js`)
Фізичний рушій працює на фіксованій частоті `60 Hz` (3 підкроки на кадр) із просторовим хешуванням зіткнень (`Spatial Hash Grid`) та підвищеним коефіцієнтом пружності (`restitution: 0.82`):

* **Зелена зона (`voicePulse`)**: навіть легкі сплески голосу до входу в жовту зону створюють помітний мікро-імпульс окремих кульок, даючи миттєвий візуальний зворотний зв'язок.
* **Жовта зона (`stirBalls`)**: при шепоті або робочому гулі кульки в нижній третині екрана активно підстрибують, обертаються та пружно деформуються (`squash & stretch`).
* **Червона зона (`scareBounce` + `chaosAgitate`)**:
  * При вході в червону зону та на кожному повторі звукового сигналу спрацьовує потужний імпульс `scareBounce` (до `42` одиниць), що підкидає всі кульки до верхньої частини екрана.
  * Протягом усього часу перебування в червоній зоні `chaosAgitate` підтримує інтенсивне буцання та зіткнення кульок у повітрі пропорційно силі шуму.
* **Режим «Перерва» (`bounceBalls`)**: висота стрибків прямо пропорційна гучності голосу чи оплесків (`×38`).

### 3. 10 Процедурних тем оформлення (100% DMCA / Trademark-Safe)
Усі персонажі та об'єкти генеруються виключно програмним кодом на HTML5 Canvas 2D без зовнішніх зображень чи захищених торгових марок:

1. **«Крафт-Куби» (`craft` — Піксель-світ)**:
   * Ізометрично-фасковані воксельні куби з піксельною сіткою `8×8` та 6 архетипами: *Кріпко* (у червоній зоні миготить білим перед «вибухом»), *Стіві*, *Ендер* (із фіолетовими очима), *Хрюша* (з 3D-п'ятачком), *Слаймик* (напівпрозорий блок із ядром) та *Ред-ТНТ* (із гнотом та іскрою).
   * У режимі золотого комбо над блоками з'являються піксельні алмази.
2. **«Блокс-Герої» (`blox` — Оббі-аватари)**:
   * Глянцеві циліндричні голови аватарів із верхнім студ-кріпленням та комірцями: *Нубік*, *Бейкон* (із хвилястою зачіскою), *Оббі-Квін*, *Будівельник у касці*, *Кібер-Блокс* (із неоновим візором) та *Голд-Лорд*.
   * Міміка реагує на шум: спокійна фірмова усмішка набік у тиші, піднята мемна брова в жовтій зоні та панічний вираз *«OOF!»* у червоній.
3. **«Бійці Арени» (`brawl` — Зіркова ліга)**:
   * Яскравий cel-shaded векторний стиль із товстим чорним контуром та обертовим кільцем «супер-заряду» під час комбо тиші або тривоги: *Кактус Спайкі* (з червоною квіткою на маківці), *Хамелеон* (у капюшоні з ґудзиками-очима), сонний *Дрімун* (із зіркою та бульбашкою сну), *Ворон*, *Лучадор* та *Меха-Вольт*.
4. **«Сплюшки» (`critters` — Монстрики)**: 6 ілюстративних пухнастих персонажів (*Буль, Пухан, Зірка, Шуршик, Моргун, Ластик*) із хмаринками снів.
5. **«Космос» (`space`)**: планети Сонячної системи з кільцями Сатурна та лінією термінатора.
6. **«Бульбашки» (`bubbles`)**: мильні бульбашки з іризацією, які можна лопати кліком/дотиком на інтерактивній дошці.
7. **«Емоджі» (`emoji`)**, **«Глянець» (`plastic`)**, **«Числа 1–10» (`numbers`)**, **«Очі» (`eyes` — стежать за курсором)**.

### 4. Інтерфейс Liquid Glass та Менеджер груп зі статистикою (`src/ui/`)
* **Liquid Glass Design System (`src/styles/main.css`)**:
  * Усі головні капсульні перемикачі (верхній перемикач режимів, лівий швидкий перемикач груп, сегментовані контролери в панелі) побудовані на багатошаровому склі з `backdrop-filter: blur(22px) saturate(190%)`, верхнім спекулярним бліком та об'ємною активною лінзою.
  * Повна підтримка контрастного профілю **«Світлий режим» (`light-room`)** за стандартом WCAG AAA для роботи на шкільних проекторах у сонячних кабінетах.
* **Швидкий перемикач на головному екрані (HUD Left)**:
  * Розташований у лівому верхньому куті поруч зі світлофором шуму.
  * Дозволяє в один клік перемикатися між групами/потоками (`4-Б`, `3-А`, `5-А` тощо) і одразу показує бейдж кількості виконаних завдань (`✓N`).
* **Менеджер груп та Ціль (`src/ui/teacher-panel.js`, `src/game/storage.js`)**:
  * Інлайн-додавання нових груп без модальних вікон браузера та можливість видалення записів.
  * Інтерактивне табло телеметрії з 4 показників для кожної групи:
    * **Усього зірок** (`totalStars`) — сумарна кількість зірок, зароблених за весь час.
    * **Завдань** (`tasksCompleted`) — автоматично збільшується на `+1` після завершення таймера завдання або вручну кліком по плитці `+1`.
    * **Призів** (`goalsReached`) — скільки разів група повністю закривала ціль банки.
    * **Час тиші** (`quietSeconds`) — сумарний час роботи в зеленій зоні (у хвилинах).
  * Скидання поточних зірок банки (`0/Ціль`) для старту нової цілі зберігає всю історичну статистику групи.

│   └── styles/
│       └── main.css            # Дизайн-система Liquid Glass, адаптивна верстка та теми

## Гарячі клавіші

| Клавіша | Дія |
| :---: | :--- |
| `Space` | Пауза / Відновлення симуляції |
| `M` | Увімкнення / Вимкнення мікрофона |
| `C` | Швидке калібрування фону кімнати (3 с) |
| `F` | Повноекранний режим (Fullscreen) |
| `1` | Режим «Тиха робота» |
| `2` | Режим «Робота в групах» |
| `3` | Режим «Перерва / Класика» |
| `T` | Старт / Пауза активного таймера завдання |
| `S` | Вручну нарахувати `+1` зірку з анімацією польоту в банку |
| `H` | Відкрити / Закрити Панель вчителя |

## Конфіденційність
Звуковий потік аналізується виключно локально в оперативній пам'яті браузера через Web Audio API. Жодні аудіозаписи чи дані не записуються і не передаються на зовнішні сервери.
