# «Тихий клас» (Quiet Class v8) — Bouncy Balls Pro

> **Інтерактивний візуальний шумомір, менеджер навчальних груп та ігровий асистент контролю тиші для шкіл, уроків, смарт-дошок (TV) і проекторів.**
> Повністю автономний PWA-додаток із процедурною графікою Canvas, інтерфейсом у стилі **[Friendly Arcade](https://github.com/Figarist/friendly-arcade)**, компресованим Web Audio синтезатором та стабілізованою Verlet-фізикою кульок і кубів.

## Ключові можливості (v8.0)

### 1. Аудіосистема, миттєве прев'ю та повторення сигналів (`src/audio/`)
Працює однаково точно на **віддалених вебкамерах (2–4 м)**, вбудованих мікрофонах ноутбуків та гарнітурах, а звукові сигнали чітко прорізають гамір класу на динаміках телевізора чи проектора:

* **Web Audio DSP-тракт мікрофона (`src/audio/mic.js`)**:
  * **120 Hz Highpass Filter**: зрізає низькочастотний гул кулерів ПК/проектора, шум кондиціонера та вібрації парт.
  * **2.2 kHz Speech Presence Filter**: підсилює діапазон розбірливості мовлення (`+3.5 dB`), виділяючи шепіт і приголосні над фоновим шумом.
  * **Preamp Gain Boost**: програмне підсилення вхідного сигналу від `0.5×` до `4.5×` (за замовчуванням `2.2×` для вебкамер).
  * **Анти-луп захист (`isMutingMic`)**: автоматично ігнорує власні звукові ефекти гри протягом `750 мс`, щоб динаміки ТВ не викликали повторне спрацювання мікрофона.
* **Синтезатор сигналів із лімітером та підтримкою власних звуків (`src/audio/sfx.js`, `sound-library.js`)**:
  * **Апаратний `DynamicsCompressorNode` (`-3 dB`, ratio `20:1`)**: надійний лімітер без агресивного підсилення та накачки гучності — звуки не пробивають стіни сусідніх кабінетів.
  * **Плавне наростання гучності при шумі**: перший сигнал звучить дуже тихо (45% від обраної гучності); наступні повтори поступово підсилюються (+20% за раз) до 100%. Щойно клас замовк — рівень скидається.
  * **Вбудовані м'які звуки**:
    1. **«Тшшш» (`shush`)**: делікатний рожевий шепіт із плавним наростанням без пронизливого транзієнта.
    2. **«Кришталь» (`chime`)**: чистий дзвін синусоїди з тривалим згасанням.
    3. **«Скринька» (`musicbox`)**: три низхідні ноти пентатоніки.
    4. **«Сова» (`owl`)**: теплий середньочастотний акустичний «у-гу».
    5. **«Крапля» (`drop`)**: подвійна крапля води.
    6. **«Вдих-видих» (`breath`)**: заспокійливий амбієнтний шум дихання.
    7. **«Радар» (`beep`)**, **«Дзвоник» (`bell`)**, **«Аркада» (`arcade`)**: пом'якшені версії класичних сигналів.
  * **Власні звуки з кешуванням в IndexedDB (`src/audio/sound-library.js`)**:
    * Завантаження будь-яких MP3/WAV/OGG аудіофайлів (до 12 штук). Автоматичний моно-мікс, обрізка до 5 с та нормалізація піку до безпечних -6 dB.
    * Звук зберігається у браузерній базі `IndexedDB` — видалення оригінального файлу з «Завантажень» не впливає на роботу.
    * Звуки автоматично зберігаються в бекап-файл `.json` (base64) і відновлюються на інших пристроях.
  * **Прив'язка окремого звуку до класу**:
    * У вікні редагування класу можна призначити індивідуальний сигнал для кожного класу або гуртка.
  * **Інтервал повторення сигналу при тривалому шумі (`alertRepeatSec`)**:
    * Налаштовується прямо в панелі: **«Кожні 2 с»**, **«Кожні 4 с»**, **«Кожні 8 с»** (за замовчуванням) або **«1 раз»**.

### 2. Стабілізована Verlet-фізика кульок, кубів та інтерактивних вікон (`src/world/`)
Фізичний рушій працює на фіксованій частоті `60 Hz` (3 підкроки на кадр = `180 Hz`) із динамічним просторовим хешуванням зіткнень (`Spatial Hash Grid`) та стабілізованим солвером:

* **Масштабування розміру (`0.2× .. 2.0×`) без інфініті-баунсу**:
  * У меню «Кульки» доступний повзунок розміру від **`0.2×`** (дрібні) до **`2.0×`** (великі) з кроком `0.1`.
  * Розділення перекриття (overlap) синхронно зміщує поточні й попередні координати Верле (`x, y` та `px, py`), а сортування знизу вгору (bottom-up) із вагою опори на підлогу гарантує спокійне вкладання купи кульок без самозбудження чи вічних стрибків.
* **Безумовно стабільна пружина сквіша та нахилу (`src/world/ball.js`)**:
  * Деформація `squash & stretch` (`[0.72, 1.28]`) та пружина неваляшки (`±25°`) інтегруються напівнеявним методом Ейлера з підкроками `120 Hz`, що виключає резонанс навіть під час фрізів вкладки.
* **Точна геометрія для сфер і кубів (`getBallExtent`)**:
  * Круглі теми використовують сферичний радіус, а блочні теми (**«Крафт-Куби»** `craft` та **«Блокс-Герої»** `blox`) — опорну функцію повернутого скругленого квадрата Мінковського з вирівнювальним моментом обертання на плоских поверхнях.
* **Фізичне перетягуване вікно «Мої класи» та стінка Налаштувань**:
  * Вікно класів можна перетягувати мишкою або пальцем у будь-яке місце екрана (позиція зберігається в `localStorage`).
  * Кульки та кубики реалістично відскакують від скругленого хітбоксу вікна (`border-radius: 20px`), котяться по його даху та розлітаються при швидкому русі вікна. Анти-краш логіка (`computeUnpinchedEscape`) не дає затиснути кульку між вікном і краєм екрана.
  * Панель «Налаштування» при відкритті виштовхує кульки вліво й слугує фізичною правою стінкою арени.
* **Реакція на голос за зонами**:
  * **Зелена зона (`voicePulse`)**: легкі мікро-імпульси окремих кульок при підвищенні фону.
  * **Жовта зона (`stirBalls`)**: помітне підстрибування та ворушіння кульок при шепоті чи робочому гулі.
  * **Червона зона (`scareBounce` + `chaosAgitate`)**: високий стрибок усіх кульок при вході в червону зону та активне бурління до повернення тиші.
  * **Режим «Перерва» (`bounceBalls`)**: висота стрибків прямо пропорційна гучності голосу чи оплесків.

### 3. 13 процедурних тем оформлення (`src/render/themes/`)
Усі персонажі малюються кодом на HTML5 Canvas 2D: жодних картинок, спрайтів чи чужих персонажів. Теми натхненні жанрами, які люблять діти (піксельні пісочниці, блочні оббі, арена-файтинги, колекційні звірята), але кожен персонаж — оригінальний.

Кожна тема має 4 стани, які діти «читають» з першого погляду:

| Стан | Коли | Що бачать діти |
| :--- | :--- | :--- |
| `sleeping` | зелена зона | закриті очі, спокійна усмішка, «Zzz» |
| `stirring` | жовта зона | очі відкриваються, підозрілий погляд, брови |
| `chaos` | червона зона | вирячені очі, роззявлений рот, іскри / мигання / піт |
| `golden` | 2+ хв суцільної тиші | щасливі очі ^ ^, рум'янець, золоте кільце й нагорода над головою |

| # | Тема (`id`) | Форма | Персонажі |
| :---: | :--- | :---: | :--- |
| 1 | **Крафт-Куби** (`craft`) | куб | Піксельна сітка `8×8` з шумовою текстурою й фаскою: *Кріпко* (миготить білим, коли шумно), *Шахтар*, *Ендер*, *Хрюша*, *Слаймик*, *Ред-ТНТ* (ґніт іскрить), *Бджілка* (крильця махають швидше від шуму), *Жабка*. Золото — піксельний алмаз. |
| 2 | **Блокс-Герої** (`blox`) | куб | Блочні голови-циліндри зі студом і плечима: *Нубік*, *Бейкон*, *Зірочка*, *Будівельник* (каска), *Геймер* (навушники мигають), *Ніндзя*, *Король* (корона), *Зомбі*. |
| 3 | **Бійці Арени** (`brawl`) | куля | Cel-shading, товстий контур, великі очі з бровами: *Кактус*, *Робо* (очі-екран: риски → прямокутники → хрестики → сердечка), *Акула*, *Грибок*, *Дракоша* (дим із носа), *Ніндзя-Кіт*, *Лучадор*, *Бомбік*. Золото — зіркова медаль. |
| 4 | **Стихійці** (`elements`) | куля | Звірята стихій: *Іскрик* (блискавки), *Вогник* (полум'я на лобі росте від шуму), *Хвилька*, *Листочок*, *Соня* (завжди напівсонна), *Камінчик*, *Крижик*, *Привидко*. Золото — значок стихії. |
| 5 | **Капібари** (`capy`) | куля | Мандаринка, каченя, квітка, полуниця, листочок чи бантик на голові; сплячі пускають бульбашку з носа, у червоній зоні мандаринка хитається. |
| 6 | **Смаколики** (`sweets`) | куля | Кавай-їжа: пончик, полуниця, кавун, печенько, мандарин, авокадо, яблучко, персик. |
| 7 | **Сплюшки** (`critters`, за замовчуванням) | куля | *Буль, Пухан, Зірка, Шуршик, Моргун, Ластик*; у золотому режимі кожен третій бачить сон (зірка, серце, корона, місяць). |
| 8 | **Космос** (`space`) | куля | Земля, Марс, Юпітер, Сонце, Місяць, Нептун з термінатором і кільцями. |
| 9 | **Бульбашки** (`bubbles`) | куля | Мильні бульбашки з іризацією; їх можна лопати дотиком на дошці. |
| 10 | **Емоджі** (`emoji`) | куля | Жовті смайлики з мімікою за зоною. |
| 11 | **Глянець** (`plastic`) | куля | Глянцеві пластикові кулі. |
| 12 | **Числа** (`numbers`) | куля | Кулі з числами 1–10 (для молодших класів). |
| 13 | **Очі** (`eyes`) | куля | Очі, що стежать за курсором чи пальцем. |

Кубічні теми (`craft`, `blox`) мають власну геометрію зіткнень (див. розділ 2). Як додати нову тему — в [AGENTS.md](AGENTS.md#themes-srcrenderthemes).

### 4. Інтерфейс для вчителя, резервні копії та PWA (`src/ui/`, `src/game/storage.js`)
Інтерфейс побудований так, щоб вчитель розібрався за кілька секунд без інструкції. Детальний посібник: **[docs/TEACHER_GUIDE.md](docs/TEACHER_GUIDE.md)**.

* **Плаваюче вікно «Мої класи» (`src/ui/class-sidebar.js`)**:
  * Перетягується за шапку чи рамку в будь-яке зручне місце на інтерактивній дошці.
  * Кожен клас — окрема картка: назва, банка зірок `12/20`, смужка прогресу, приз 🎁 і зірки за весь час 🏆.
  * **Рейтинг**: кнопка 🏆 сортує класи за зірками за весь час із медалями 🥇🥈🥉.
  * **Вікно класу (кнопка ✎)**: назва, колір, ціль (−/+), приз, швидкість зірок `30 / 60 / 90 с тиші`, `+1 зірка`, `+1 завдання`, статистика та історія отриманих призів із датами.
* **Захист збережень та резервні копії (`src/game/storage.js`)**:
  * **Експорт та імпорт `.json`**: збереження всіх класів, зірок і налаштувань у файл на флешку чи диск та відновлення в 1 клік.
  * **Авто-зліпки (останні 5 станів)**: автоматично створюються при додаванні/видаленні класів, досягненні цілі, скиданні банки та перед імпортом.
  * **`Persistent Storage API`**: захищає сховище браузера від автоматичного очищення при нестачі місця на диску.
* **PWA та встановлення на ПК**:
  * Фірмові іконки з монстриками (`public/icon.svg`, `icon-192.png`, `icon-512.png`), повна офлайн-робота через Service Worker (`public/sw.js`) та кнопка **«Встановити додаток на ПК»** прямо в меню налаштувань.

## Гарячі клавіші

| Клавіша | Дія |
| :---: | :--- |
| `Space` | Пауза / Відновлення симуляції |
| `M` | Увімкнення / Вимкнення мікрофона |
| `C` | Швидке калібрування фону кімнати (3 с) |
| `F` | Повноекранний режим (Fullscreen) |
| `1` | Режим «Тиха робота» |
| `2` | Режим «Робота в групах» |
| `3` | Режим «Перерва / Класика» |
| `T` | Пауза / продовження активного таймера (запуск — кнопка «Таймер» зверху) |
| `S` | Вручну нарахувати `+1` зірку активному класу з анімацією польоту в банку |
| `H` | Відкрити / Закрити налаштування |
| `Esc` | Закрити спливаюче вікно |

## Встановлення та збірка

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Запуск локального сервера з симулятором шуму (?debug)
npm run dev:test

# Запуск модульних тестів (Vitest)
npm test

# Створення виробничої збірки в папку dist/
npm run build

# Перевірка готової збірки dist/ через автономний локальний сервер
npm run serve:test

# Деплой: просто git push у main — GitHub Actions перевірить тести і опублікує сайт (див. DEPLOY.md)
```

## Конфіденційність
Звуковий потік аналізується виключно локально в оперативній пам'яті браузера через Web Audio API. Жодні аудіозаписи чи дані не записуються і не передаються на зовнішні сервери.
