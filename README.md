# 🤫 «Тихий клас» (Quiet Class v5) — Bouncy Balls Pro

> **Інтерактивний візуальний шумомір та ігровий асистент контролю тиші для шкіл, уроків, смарт-дошок (TV) та проекторів.**
> Повністю автономний PWA-додаток, створений для утримання уваги учнів через живу фізику персонажів, ігрові нагороди та адаптивну аудіосистему.

---

## 🌟 Ключові можливості

### 1. 🎙️ Адаптивна аудіосистема для будь-яких мікрофонів
Працює однаково точно на **віддалених веб-камерах (2–4 м)**, вбудованих мікрофонах ноутбуків, гарнітурах і студійних мікрофонах:
* **Web Audio DSP Pipeline**:
  * **120 Hz Highpass Filter**: ефективно зрізає гул вентиляторів ПК/проектора, низькочастотний шум кондиціонера та вібрації столу.
  * **2.2 kHz Speech Presence Filter**: підсилює діапазон розбірливості людського голосу (+3.5 dB), виділяючи тихий шепіт і приголосні звуки над фоновим шумом.
  * **Preamp Gain Boost**: програмне підсилення сигналу від 0.5× до 4.5× (за замовчуванням **2.2×** для вебкамер).
* **Вибір аудіопристрою (Input Device Selector)**: меню вибору між усіма підключеними мікрофонами (вебкамера, масив мікрофонів, USB-аудіо).
* **Профілі обладнання**: швидкі перемикачі:
  * 📷 **Вебкамера (2–4 м)**: фільтр кулерів + підсилення 2.2× + чутливі пороги.
  * 💻 **Ноутбук / ПК**: помірне підсилення 1.5×.
  * 🎙️ **Гарнітура**: прямий сигнал 1.0×.
* **Живий VU-тестер**: кольорова шкала в панелі налаштувань із реальними показниками dB та миттєвою реакцією на голос для перевірки перед уроком.
* **Розумне автокалібрування**:
  * Розраховує **25-й перцентиль** фону кімнати, тому випадковий кашель чи скрип стільця не спотворюють калібрування.
  * Автоматичне обмеження (clamp) в межах `[-75 dB, -44 dB]` запобігає «оглухненню» додатку в шумному приміщенні.
  * **Leaky Silence Tracking**: якщо в класі зберігається тиша, фоновий рівень непомітно й плавно підлаштовується під ідеальну тишу.

---

### 2. ⚡ Швидкі пороги та жива реакція
* **Тиха робота (Quiet Work)**:
  * **Жовта зона (+4.5 dB, 120 мс)**: навіть тихий шепіт або рух зошитів змушує персонажів прокидатися, тремтіти й підстрибувати.
  * **Червона зона (+9.0 dB, 250 мс)**: будь-яка розмова або вигук активує переляканий стрибок персонажів (`scareBounce`), струшування екрана, підстрибування банки зірок та звукове попередження («Тсссс» або м'який біп).
* **Робота в групах (Groups)**:
  * Дозволений помірний робочий шепіт (жовта зона: +8.0 dB, червона: +15.0 dB).
* **Перерва / Класика (Breaktime)**:
  * Кульки весело стрибають від гучності голосу пропорційно силі крику.

---

### 3. 🎨 Anti-Slop графіка та тактильний UI
* **Ніяких системних емодзі**: всі значки інтерфейсу виконані у вигляді векторних SVG-іконок з круглими кутами та єдиною товщиною штриха (`stroke-width: 2.2`).
* **Справжні контактні тіні**: під кожною кулькою розраховується м'яка еліптична тінь, що змінює розмір і розмиття під час стрибка.
* **Фізика неваляшки (Roly-Poly)**: 3D-градієнт, світловий блік зверху-зліва та нижній рефлекс зафіксовані у світових координатах, а обличчя пружно погойдується на `±25°`.
* **7 тематичних світів**:
  1. **Сплюшки**: 6 виразних героїв (Буль, Пухан, Зірка, Шуршик, Моргун, Ластик).
  2. **Космос**: Земля, Юпітер, Місяць, Сатурн із чесними кільцями у два проходи та лінією термінатора.
  3. **Бульбашки**: хроматичні переливи та лопання при натисканні.
  4. **Емоджі**, **Глянець**, **Числа**, **Очі**.
* **Режим «Світла кімната» (Light Room)**: контрастний світлий профіль для яскравих шкільних проекторів і сонячних класів.

---

### 4. 🏆 Мотивація та Банка зірок
* **Скляна векторна банка**: прогрес заповнення зірками всередині банки відповідно до цілі класу.
* **Політ нагороди**: за кожні 30 секунд чистої тиші з центру вилітає велика золота зірка по кривій Безьє прямо в шийку банки із дзеленчанням.
* **Золотий комбо-режим**: після 2 хвилин безперервної тиші персонажі світяться аурою та випускають хмаринки снів (зірочки, сердечка, місяць).
* **Таймер завдань**: таймер на 1–15 хвилин із бонусною зіркою за успішну тиху роботу.
* **Керування кількома класами**: ведення зірок для різних класів (наприклад, 4-Б, 3-А, 5-В) із кнопкою скидання на новий тиждень та налаштуванням призу (мультик, настільна гра).

## 🚀 Встановлення та розробка

### Вимоги
* Node.js v18+ 
* Браузер із підтримкою Web Audio API (Chrome, Edge, Firefox, Safari)

### Команди
```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки (http://localhost:5173)
npm run dev

# Запуск юніт-тестів (Vitest)
npm test

# Створення виробничої оптимізованої збірки
npm run build

# Попередній перегляд збірки
npm run preview
```

## 🌐 Розгортання на хостингу

1. Виконайте збірку:
   ```bash
   npm run build
   ```
2. Вміст сформованої папки `dist/` завантажте на ваш веб-хостинг (наприклад, у `public_html/` або `public_html/bouncy/` на `sivochka.com`).
3. **Важливо**: доступ до мікрофона в сучасних браузерах вимагає обов'язкового **HTTPS** (окрім `localhost`). Переконайтеся, що на вашому домені активний SSL-сертифікат.
4. Додаток автоматично кешується Service Worker'ом і після першого запуску працює **повністю офлайн** без інтернету.

## 🛡️ Конфіденційність
Звуковий потік аналізується виключно локально у браузері через Web Audio API. Жодні аудіозаписи чи дані не записуються і не передаються на зовнішні сервери.
