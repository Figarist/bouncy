# Інструкція розгортання «Тихий клас» на sivochka.com

## 0. Звичайний реліз: просто `git push`
Сайт https://sivochka.com/bouncy/ — це власний GitHub Pages цього репозиторію (як OGCruncher).
Кожен пуш у `main` запускає [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml): `npm test` → `npm run build` → публікація `dist/`.
Якщо тести впали, сайт не оновлюється. Хід деплою видно у вкладці **Actions** на GitHub (1–2 хвилини).

* Версію кешу Service Worker міняти руками не треба: під час збірки плагін `sw-manifest` у `vite.config.js` вписує в `dist/sw.js` хеш збірки і список файлів для офлайну.
* Після деплою вчитель побачить вгорі тост: «Оновлено» (якщо сторінку вже відкрито на новій версії) або «Доступна нова версія» з кнопкою «Оновити» (якщо вкладка була відкрита до деплою; вкладки перевіряють оновлення раз на 30 хв і при поверненні на вкладку).
* Папка `dist/` у git не комітиться.
* Перезапустити деплой без коміту: Actions → «Test & Deploy» → **Run workflow**.

Нижче — ручне розміщення на звичайному хостингу.


## 1. Створення збірки
У терміналі виконайте:
```bash
npm run build
```
Після виконання команди формується папка `dist/`. У ній містяться всі оптимізовані файли гри:
* `index.html` — основна сторінка з підключеним PWA-маніфестом та JSON-LD розміткою;
* `assets/` — зібрані скрипти (включно з 13 процедурними темами, менеджером груп, резервним копіюванням та аудіокомпресором), стилі Friendly Arcade та локальні шрифти (Nunito, Rubik);
* `icon.svg`, `icon-192.png`, `icon-512.png` — векторні та растрові іконки PWA;
* `manifest.webmanifest` — конфігурація для встановлення гри як додатка;
* `sw.js` — Service Worker для повної офлайн-роботи в класі без інтернету;
* `.htaccess` — правила стиснення Gzip/Brotli та кешування статики для Apache/LiteSpeed хостингів.

Всі внутрішні шляхи у збірці є відносними (`./`), тому гру можна розмістити:
* У корінь сайту: `https://sivochka.com/`
* У підпапку: `https://sivochka.com/bouncy/` або `https://sivochka.com/quiet-class/`

---

## 2. Завантаження на хостинг
1. Відкрийте ваш FTP-клієнт (FileZilla, WinSCP) або «Диспетчер файлів» у cPanel вашого хостингу.
2. Перейдіть у цільову папку (наприклад, `public_html/` або створіть підпапку `public_html/bouncy/`).
3. Завантажте **весь вміст папки `dist/`** (включаючи прихований файл `.htaccess`, якщо він приховується вашим файловим менеджером).

---

## 3. Важливо: обов'язковий HTTPS
> [!IMPORTANT]
> Браузери (Chrome, Edge, Safari, Firefox) з міркувань безпеки дозволяють доступ до мікрофона **лише через захищене з'єднання HTTPS** (або на `localhost`).
> Переконайтеся, що на домені `sivochka.com` активовано SSL-сертифікат (Let's Encrypt у панелі хостингу вмикається безкоштовно).

---

## 4. Офлайн-робота (PWA)
* Завдяки вбудованому `sw.js`, гра при першому відкритті зберігає всі необхідні ресурси в локальний кеш браузера.
* Якщо в школі пропаде інтернет або Wi-Fi, гра продовжить працювати без збоїв.
* Вчителі можуть встановити гру як окремий настільний додаток через кнопку **«Встановити додаток на ПК»** у налаштуваннях або іконку в адресному рядку браузера для швидкого запуску на уроці в один клік на повний екран.
